# SOUL AGENCY

**Веб-студия полного цикла**

## О проекте

SOUL AGENCY - современный лендинг и портфолио веб-студии.  
Проект демонстрирует примеры сайтов, реализованных агентством, с интерактивным слайдером, адаптивным дизайном и формой заявки.

## Быстрый старт

1. Клонируйте репозиторий или скачайте архив.
2. Откройте проект в WebStorm или другом редакторе.
3. Запустите локальный сервер (например, встроенный в WebStorm или через `npx http-server`).
4. Откройте `index.html` в браузере.

---

## Особенности

- **Фиксированное меню** и всегда доступные кнопки заказа
- **Полноэкранный слайдер** с подписями и кратким описанием для каждого примера сайта
- **Адаптивный дизайн** для мобильных и десктопных устройств
- **Форма заявки** с выезжающей панелью справа
- **SVG-иконки** для меню и кнопок
- **Плавная прокрутка** к разделам страницы
